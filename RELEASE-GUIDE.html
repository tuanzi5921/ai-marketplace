一、P0 修复清单

本次发布修复了全部 P0 级阻断问题，覆盖后端接口缺失、前后端契约不一致、安全配置缺陷三大类。

1.1 后端接口修复

编号问题修复状态
P0-1 schema.sql 中 admin 密码哈希为占位值，must_change_password 不一致 新增 DataInitializer（CommandLineRunner），启动时自动校验并重新生成 BCrypt 哈希，强制 must_change_password=1 已修复
P0-2 GlobalExceptionHandler 对 401 异常返回 HTTP 200，前端无法识别未授权 改用 ResponseEntity 返回对应 HTTP 状态码，新增 mapToHttpStatus() 方法映射业务码到 HTTP 状态码 已修复
P0-3 审核接口路径 /review 与前端 /reviews 不匹配 修改 ReviewController 的 @RequestMapping 为 /reviews，通过/驳回接口统一用 @RequestParam 传 reason 已修复
P0-4 作品下载接口前端调 POST、后端实现 GET；管理端缺少列表/下架/删除接口 download 改为 POST；新增 adminList、offline、delete 三个管理端接口 已修复
P0-5 DashboardController 缺失，前端管理后台看板页面无法加载数据 新建 DashboardController，暴露 GET /admin/dashboard/stats 接口，对接已有 DashboardService 已修复

1.2 前后端契约统一

编号问题修复状态
P0-10 分页响应字段不一致：后端返回 records/current，前端期望 list/page 创建 PageResult<T> DTO，统一字段为 list/total/page/size；前端 submission.ts、Home.vue、Me.vue 全部同步 已修复
P0-FE 前端 workbench vite.config.ts 硬编码 API 地址；Me.vue 使用旧 records 字段 vite.config.ts 改用 loadEnv 读取环境变量；Me.vue 中 res.records → res.list 已修复

四、部署步骤

4.1 上传发布包

# 从开发机上传到应用服务器
scp dist-release/ai-marketplace-release-*.tar.gz aiuser@192.168.1.132:/tmp/

4.2 执行发版脚本

# SSH 到应用服务器
ssh aiuser@192.168.1.132

# 用 sudo 执行发版脚本（自动备份旧版 + 替换 + 重启）
sudo bash /aitest/scripts/deploy-release.sh /tmp/ai-marketplace-release-*.tar.gz

deploy-release.sh 会自动完成以下操作：

  • 备份当前 jar 为 ai-marketplace.jar.prev-<时间戳>（保留最近 3 个）
  • 替换后端 jar 到 /aitest/app/releases/ai-marketplace.jar
  • 替换前端产物到 /aitest/www/workbench 和 /aitest/www/admin
  • 保留企微域名验证文件 WW_verify_*.txt
  • 重启 systemd 服务 ai-marketplace
  • 等待端口 8080 监听就绪（最多 60 秒）
  • Nginx reload

4.3 只更新前端（如仅改前端）

# 直接覆盖静态产物
sudo cp -r frontend-workbench/dist/. /aitest/www/workbench/
sudo cp -r frontend-admin/dist/. /aitest/www/admin/
sudo nginx -t && sudo systemctl reload nginx

4.4 数据库变更（如有）

# 在数据层服务器执行
ssh aiuser@192.168.1.131
sudo mysql < /aitest/sql/<变更脚本>.sql
本次发布无需数据库结构变更。schema.sql 的 admin 密码哈希修复由 DataInitializer 在应用启动时自动处理，不依赖手动 SQL 操作。

六、回滚方案

6.1 后端回滚

发版脚本自动保留了最近 3 个历史版本。回滚命令在发版完成时也会打印出来：

# 查看可用历史版本
ls -lt /aitest/app/releases/ai-marketplace.jar.prev-*

# 回滚到上一版
sudo cp /aitest/app/releases/ai-marketplace.jar.prev-<时间戳> \
       /aitest/app/releases/ai-marketplace.jar
sudo systemctl restart ai-marketplace

# 确认启动
sudo systemctl status ai-marketplace
ss -ltn 'sport = :8080' | grep 8080

6.2 前端回滚

前端没有自动备份机制。如需回滚，重新执行上一版的 build-release.ps1 并部署，或直接覆盖上一次的 dist 目录。

# 如有上一版 dist 备份
sudo cp -r /backup/workbench-dist/. /aitest/www/workbench/
sudo cp -r /backup/admin-dist/. /aitest/www/admin/
sudo nginx -t && sudo systemctl reload nginx

6.3 数据库回滚

本次发布不涉及数据库结构变更，无需回滚数据库。日常备份恢复方式：

# 从自动备份恢复（每日 02:00 生成）
gunzip < /aitest/mysql/backup/ai_marketplace_YYYYmmdd_HHMMSS.sql.gz | sudo mysql
